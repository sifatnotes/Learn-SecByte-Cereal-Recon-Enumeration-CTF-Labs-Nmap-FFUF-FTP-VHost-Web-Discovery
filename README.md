# Learn SecByte Cereal Recon & Enumeration CTF Labs

A curated collection of **hands-on cybersecurity labs and CTF challenges** focused on reconnaissance, web enumeration, network scanning, virtual hosts, fuzzing, FTP discovery, source inspection, backup hunting, and PHP deserialization.

These labs are useful for **cybersecurity students, CTF players, pentesters, SOC analysts, and security learners** building practical reconnaissance and enumeration skills in authorized environments.

## Introduction

This repository organizes Learn SecByte labs around the **Cereal CTF environment** and related reconnaissance challenges. The collection covers tools and concepts such as **Nmap, FFUF, FTP, virtual host discovery, web enumeration, source analysis, backup discovery, and PHP deserialization**.

The repository serves as a searchable learning index rather than a collection of flags, credentials, or exploit answers.

## How to Use the Labs

1. Open a lab through its direct Learn SecByte URL.
2. Read the objectives and understand the authorized scope.
3. Perform reconnaissance only against the provided lab environment.
4. Practice identifying hosts, ports, services, virtual hosts, web resources, source information, and other exposed assets.
5. Use the exercises to understand how reconnaissance findings contribute to security assessment workflows.
6. Document your observations and defensive lessons without publishing sensitive credentials or unauthorized access information.
